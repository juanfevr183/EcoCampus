01 / FORMULACIÓN DEL PROBLEMA

Un pequeño error cambia todo el proceso.

En la universidad se generan residuos aprovechables, orgánicos y no aprovechables. Algunas personas no identifican el contenedor correcto y, durante los momentos de alta circulación, ciertos puntos pueden llenarse antes de que el personal de servicios generales los revise. Esto puede contaminar materiales reciclables, generar malos olores y dificultar la recolección.

Relevancia social y económica: una separación más clara puede favorecer el aprovechamiento de materiales, mejorar el orden del campus y apoyar el trabajo del personal encargado.

Alcance del proyecto

Prototipo académico para orientar la clasificación de residuos y recibir reportes voluntarios de contenedores llenos en un conjunto limitado de puntos del campus. No reemplaza las rutas institucionales ni pretende gestionar los residuos de toda la ciudad.

02 / NUESTRA SOLUCIÓN

La IA como guía,
las personas como decisión final.

La persona selecciona o fotografía un residuo. El sistema propuesto analiza la imagen, estima una categoría y muestra una recomendación con un nivel de confianza. Si la imagen es confusa o el residuo está mezclado, solicita verificación humana.

01

Captura

El usuario selecciona o fotografía el residuo desde su celular.

02

Analiza

Un modelo de visión por computador estima si es aprovechable, orgánico o no aprovechable.

03

Orienta

La interfaz muestra una sugerencia y advierte cuando se requiere revisión humana.

Alternativas tecnológicas evaluadas

A · Chatbot

Bajo costo y fácil actualización; depende de que el usuario describa correctamente el residuo.

B · Clasificador de imágenes

Seleccionado: ofrece orientación visual y puede prototiparse sin instalar equipos en todos los contenedores.

C · Sensores IoT

Ayudan a priorizar la recolección, pero requieren hardware, conectividad e instalación.

Hardware

Dispositivo del usuario, cámara y conexión a internet. En la fase inicial no se requieren sensores instalados en los contenedores.

Software

Frontend web, backend Python, comunicación HTTPS y almacenamiento mínimo de reportes.

Modelo de IA

Clasificador de imágenes con tres categorías generales. Debe entrenarse y validarse con ejemplos representativos del campus.

Decisiones de diseño

La web funciona desde teléfonos; el procesamiento en servidor facilita actualizar el modelo. Se eligió el clasificador por responder directamente a la duda de clasificación y evitar, inicialmente, el costo de desplegar sensores en todos los puntos.

La página actual es una demostración navegable. No envía fotografías a un servidor ni ejecuta un modelo de IA entrenado.

04 / ANÁLISIS DE FACTIBILIDAD

Un prototipo escalable por etapas.

Recursos computacionales

  • Cliente: teléfono o computador con navegador y cámara.
  • Red: conexión a internet y HTTPS para enviar imágenes.
  • Servidor: instancia capaz de ejecutar el backend Python.
  • IA: almacenamiento para el modelo y capacidad de procesamiento acorde al volumen de imágenes; una GPU podría evaluarse si el modelo y la demanda lo requieren.
  • Datos: base de datos pequeña para reportes agregados.

Costos por contemplar

  • Alojamiento web y servidor de backend.
  • Almacenamiento, transferencia de datos y copias de seguridad.
  • Entrenamiento, validación y actualización del modelo.
  • Desarrollo, soporte, mantenimiento y pruebas.
  • En una fase IoT: compra, instalación, energía y mantenimiento de sensores.

No se asignan valores monetarios porque dependen del proveedor, el tráfico, el modelo y el número de contenedores. Deben cotizarse antes de un piloto real.

06 / MARCO ÉTICO Y LEGAL

La tecnología debe cuidar a las personas.

Privacidad

Evitar capturar rostros y datos personales. Procesar únicamente la imagen necesaria para clasificar el residuo y eliminarla o anonimizarla según la política institucional.

Sesgos y errores

Las imágenes pueden variar por iluminación, ángulo, suciedad o mezcla de materiales. El modelo debe probarse con ejemplos diversos y advertir cuando su confianza sea baja.

Transparencia

Informar que la recomendación es una ayuda, no una decisión definitiva. Explicar limitaciones y permitir la verificación por parte del usuario o del personal.

Responsabilidad

La IA no reemplaza las normas de separación ni el criterio del personal de servicios generales. Los reportes deben ser voluntarios y usados solo para el propósito informado.

Referente legal colombiano: la Ley 1581 de 2012 establece disposiciones generales para la protección de datos personales y el marco de Habeas Data. Si la solución llega a tratar datos personales, la institución deberá definir finalidad, autorización cuando corresponda, medidas de seguridad, conservación y atención de derechos de los titulares. La implementación debe revisarse con las políticas y asesoría jurídica institucional; esta sección es informativa y no constituye concepto legal.

08 / DIVULGACIÓN CIENTÍFICA

Technical Abstract

EcoCampus AI: A Web-Based Artificial Intelligence Proposal for Campus Waste Sorting

Improper waste separation in university environments can contaminate recyclable materials, increase handling costs, and reduce the effectiveness of waste recovery programs. This project presents EcoCampus AI, a conceptual web-based system designed to support waste sorting and improve communication between campus users and waste management staff. The proposed methodology combines a responsive web interface with a computer vision model that analyzes an image captured by a user and estimates whether an item is recyclable, organic, or non-recyclable. The system is designed to return a suggested category and a confidence level, while requesting human verification when an image is unclear or an item contains mixed materials. Its proposed client-server architecture includes a mobile browser, an HTTPS connection, a Python backend, an image-classification model, and a minimal database for aggregated reports about full containers. Three alternatives were considered: a rule-based chatbot, an image classifier, and Internet of Things fill-level sensors. The image-classification approach was selected because it directly addresses users’ uncertainty and can be prototyped without installing hardware throughout the campus. A future IoT integration could complement classification by notifying staff when selected containers approach capacity. The prototype is a decision-support concept, not a validated autonomous system. Its expected impact will be assessed through per-class accuracy, confusion matrices, response time, usability tests, and the rate of cases requiring human review. Privacy, transparency, and institutional waste-sorting guidelines remain essential to responsible deployment.

Keywords: artificial intelligence; computer vision; waste sorting; web application; Internet of Things; sustainability.
